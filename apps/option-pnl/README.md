# Option P&L attribution

The P&L attribution selector defaults to **Pathwise Greeks**. Switching to
**End-state** immediately redraws the same detail chart without fetching or
mutating historical data. Select two chart points to set the entry and end.

- `src/lib/attribution.js`: the extracted, unchanged chart accumulation lives in
  `calculatePathwiseAttribution`. `calculateEndStateAttribution` averages all six
  spot/IV/time permutations, caching the eight hybrid prices. The series adapter
  always compares each close with the first close of the selected range.
- `lib/thalex.js`: `computeGreeksPnlSeries` and `calcGreeks` are unchanged.
  `calcOptionPrice` adds the value counterpart of this existing model, sharing
  its inputs, normal CDF and 365.25-day year convention.
- `src/App.vue`: normal reactive UI state owns `pnlAttributionMethod`.
- `src/components/OptionPnlChart.vue`: selects series and labels for the mode;
  the PNG also includes the selected attribution title and legend.

## Pricing assumptions

Historical option marks are supplied by the API, not generated by a local
surface model. The existing local Greeks model uses index spot, contract strike,
option type, time to expiry, and the specific option's historical IV. End-state
repricing uses that same zero-rate, zero-carry model and decimal `iv_close`;
there is no ATM substitution or surface interpolation. Strike and type remain
fixed. Historical forward, rate, funding, carry and surface inputs are not
available to this calculation. Their effects, and all differences between local
model values and actual marks, belong to Residual.

End-state Total equals current close mark minus entry close mark. The three
Shapley contributions plus Residual reconcile with this Total. Expired options
and zero volatility use intrinsic value. Missing/invalid model inputs leave
contributions unavailable (chart gaps), retaining actual Total when marks exist;
missing entry data is not silently replaced with a later entry.

## Legacy Total exception

The requirements to preserve pathwise behavior exactly and keep Total identical
between modes conflict on discontinuous candles: the legacy chart sums
`mark_price_close - mark_price_open` after the entry row, whereas end-state uses
`current mark_price_close - entry mark_price_close`. These coincide when candles
are continuous, but can differ across gaps. The legacy method, including its
Total and residual calculations, is preserved pending a decision to change that
behavior. Both UI explanations state their Total convention.

## Validation

Run `npm test` and `npm run build` in this directory. Tests cover flat states,
round trips and entry rebasing, pure factor moves for calls and puts, all six
Shapley orders, reconciliation against non-model marks, expiry, zero/missing IV,
legacy accumulation and delta regression, and switching without input mutation.
Continuous and gapped candle Total behavior are tested separately.
